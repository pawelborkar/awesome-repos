## Pair reading with practice

The Rust Programming Language offers a book-length route into the language. Rust By Example takes an example-driven approach, and Rustlings gives you exercises to work through. Comprehensive Rust provides a course format, while Rust Design Patterns collects recurring design approaches.

## Save specialized material for a concrete goal

The Procedural Macros Workshop focuses on one specific part of Rust. Use it when macros are what you want to explore, rather than treating it as a first introduction to everything in the language. Read the source setup instructions and choose a resource that matches the time you can give it.
