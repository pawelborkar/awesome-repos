## Choose the application foundation first

Svelte and SvelteKit are the starting points in this collection. Read their current documentation before selecting additional UI tools, because framework compatibility and setup instructions change over time.

## Add the capability you actually need

Bits UI, Skeleton, and Melt UI offer different approaches to UI building. MDsveX brings Markdown into the Svelte ecosystem, while Threlte focuses on 3D. Compare the scope of each option with your project, then try a small component or page before making a larger commitment. This is a map of options, not a recommendation to install every entry.
