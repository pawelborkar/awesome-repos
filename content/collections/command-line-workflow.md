## Improve one repeated task

ripgrep searches text, fd helps find files, and bat adds syntax highlighting to file output. zoxide focuses on navigating directories, lazygit provides a terminal interface for Git, and tldr pages supplies concise command examples.

## Keep your workflow understandable

Choose the task you repeat most often and try one tool with your own files. Read its options before changing aliases or shell configuration. Installation methods and supported platforms differ, so follow each project's current documentation. A new tool is useful when you can explain how it helps your work.
