## Build fluency a little at a time

Use 30 Days of Python for a sequence of programming challenges, or Learn Python for runnable examples. The Algorithms is useful when you want to inspect and compare implementations. Python Patterns focuses on design choices, while wtfpython explores surprising behavior through snippets.

## Choose a focus

The Python Data Science Handbook uses notebooks for a more specialized route. Begin with the format that suits your task: implement an algorithm, change a runnable example, or investigate a snippet and explain the result. These resources have different goals and are not interchangeable full courses.
