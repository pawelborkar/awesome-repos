## Learn a concept, then test it

You Don't Know JS Yet provides a deeper reading path. 33 JS Concepts organizes concepts to explore, while JavaScript Questions and wtfjs let you investigate how the language behaves. A cheatsheet helps refresh something you have already encountered.

## Keep language behavior separate from style

The Airbnb JavaScript Style Guide is useful for conventions and consistency. Style guidance serves a different purpose from an explanation of runtime behavior, so use it alongside examples rather than as your entire learning plan. Try a snippet in the environment you use and explain its output before reading further.
