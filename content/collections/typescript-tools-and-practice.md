## Decide whether you are learning or integrating

Type Challenges offers exercises for practising the type system. The TypeScript book provides a reading reference, while the TypeScript repository is the source for the language and compiler. These are useful starting points for different questions.

## Choose a tool for a concrete boundary

type-fest supplies reusable types; Zod addresses data validation; tRPC focuses on typed APIs. Each adds a different capability to a project. Check its current requirements and understand where compile-time types end and runtime behavior begins before using it at an application boundary.
